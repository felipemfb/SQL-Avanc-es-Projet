# CineExplorer

CineExplorer is an academic project developed for the **Bases de Données Avancées** course at the **Aix-Marseille Université**.  
The main goal of the project is to design and experiment with a **multi-database architecture**, combining **relational (SQL)** and **NoSQL (MongoDB)** technologies within a single application.

The project explores:
- The differences between SQL and NoSQL data models
- The use of **SQLite** for structured, relational queries
- The use of **MongoDB** for document-oriented, aggregated data
- Replication, failover, and high availability concepts using MongoDB replica sets
- Basic web integration using **Django** to expose data through a simple interface

This repository focuses on database modeling, performance considerations, and fault tolerance of the technologies with the database available.
